# 🚛 Trucking Operations & Financial Performance Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard designed to analyse trucking operations, fleet performance, revenue, costs, profitability, trips, and maintenance activity.

The dashboard transforms operational data into actionable business insights that can help management monitor financial performance, identify high-performing regions and truck types, and understand maintenance costs across the fleet.

---

## 🎯 Business Objectives

The main objectives of this project were to:

- Monitor total revenue, costs, profit, and profit margin
- Analyse monthly revenue and cost trends
- Identify the strongest-performing regions
- Analyse trip volumes by truck type
- Evaluate fleet performance
- Analyse maintenance costs across truck types
- Identify trucks with the highest maintenance costs
- Understand operational and financial performance trends
- Present key business insights through an interactive dashboard
